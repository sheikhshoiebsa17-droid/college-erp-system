# 🎓 College ERP Management System

A full-stack College ERP Management System developed using Spring Boot, Thymeleaf, Hibernate, and MySQL. The application helps manage students, faculty, courses, attendance, marks, results, and fees through a user-friendly web interface.

---

## 🚀 Features

- 🔐 Login Page
- 📊 Dashboard with Statistics
- 👨‍🎓 Student Management
- 👨‍🏫 Faculty Management
- 📚 Course Management
- 📝 Attendance Management
- 📖 Marks Management
- 🏆 Result Management
- 💰 Fee Management
- 📄 PDF Export
- 📊 Excel Export
- 🔍 Search Functionality
- 📑 Pagination
- ✅ Form Validation
- ⚠️ Global Exception Handling
- 🎨 SweetAlert2 Confirmations

## ▶️ How to Run

1. Clone the repository.
2. Open in IntelliJ IDEA.
3. Configure MySQL in `application.properties`.
4. Create the `student_management` database.
5. Run the Spring Boot application.
6. Open:

http://localhost:8080
